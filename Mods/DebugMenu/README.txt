Debug Menu 1.0.3  -  a mod for Melvor Idle 2
============================================

Opens the developers' own debug menu that ships inside the game but is never shown.

Tested with game version 0.11.6-alpha.1 and Melvor Mod Loader 0.1.3.


REQUIRES
--------
Melvor Mod Loader 0.1.3 or newer. Install the loader first.


INSTALL
-------
1. Open the game folder
   (Steam > right-click Melvor Idle 2 > Manage > Browse local files).
2. Extract this zip there. The mod ends up in the "mods" folder:
      mods\DebugMenu\DebugMenu.dll
3. Start the game.


HOW TO USE
----------
Open a character and press F9 (or pick it from the Mods button in the top bar; the key can be changed there).


GOOD TO KNOW
------------
- The menu is the game developers' tool, shown as it is. Some of its buttons change your
  character permanently. Make a backup first (the Save Backup mod does that for you).


UNINSTALL
---------
Delete the folder "mods\DebugMenu".
