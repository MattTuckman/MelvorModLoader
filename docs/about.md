# About this wiki

This wiki is the manual for **Melvor Mod Loader** and the mods built on it. It is community-made and
unofficial, and not affiliated with Games by Malcs or Jagex.

## How it is kept correct

The code examples are not just written: they are run. The loader's repository contains a test rig that starts
the game in the background on a test character and drives it from code. Every recipe in the
[Cookbook](modding/cookbook) and every example on [Building windows](modding/user-interface) is part of it, and
the [first-mod tutorial](modding/first-mod) was followed step by step to make the picture at its top.

Everything was checked against **game version 0.11.6-alpha.1** with **loader 0.1.3**. When the game updates,
the pages are checked again.

## Help improve it

- Found a mistake, or something unclear? Every page has a **"Suggest a change to this page"** link at the bottom.
  It opens the page's text on GitHub, where you can propose an edit.
- Or tell us on [Discord](https://discord.gg/q6aexZZSAf), or open an
  [issue on GitHub](https://github.com/falorfrozen-cmd/MelvorModLoader/issues).
- Learned something about the game that others should know? Add it to [Inside the game](modding/inside-the-game)
  or the [Cookbook](modding/cookbook).
