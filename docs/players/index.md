# For players

Everything you need to play Melvor Idle 2 with mods. No programming, no tools: you unzip files into the game
folder, and that is all.

{: .tip }
> In a hurry? [Install the loader](install), start the game, and look for the green
> **Melvor Mod Loader** line in the top-left corner. Then unzip the mods you want the same way.

## How it fits together

- **Melvor Mod Loader** is the one piece every mod needs. It is installed once.
- **Mods** are small add-ons. Each is one zip that you unzip into the game folder; it lands in `mods\<ModName>`.
- The game itself is not changed. Remove the loader and the game is exactly as before.
