KISA ACIKLAMA (Summary / Brief overview, 240 karakter):
One F8 window with 60+ settings and tools for Melvor Idle 2: XP and game speed, bank slots, skill bonuses, god mode, loot filter, materials no recipe needs, per-skill XP and speed, give items and levels. Not written into your save.

DEGISIKLIK LISTESI (Changelogs sekmesi):
0.5.0
- Fixed: "Skill action speed" together with a skill's own speed could stop the game (everything froze until the setting was turned off). The two now multiply (x2 and x4 are x8) and stop at x20 together. The game's own speed bonuses are counted too, including those for a single animal or recipe (Hunting journal levels, for example).
- Fixed: a speed setting changed after planting did not count for crops already growing, so their old time stayed on the plot. Crops now get their new time at once.
- New page "Materials": mark a material (Coal, for example) as not needed and no recipe or item upgrade asks for it any more.
- New setting "Astrology: knowledge per study" (up to x1000).

0.4.2
- Fixed: with Game speed above 1x, "Loading Offline Progress" could take many minutes or hang. Offline progress is now left entirely to the game.

0.4.1
- Auto-sell and the loot filter leave locked bank stacks alone

0.4.0
- New look, loot filter, "All skills at once", settings apply at once, English only

[size=5][b]Start here[/b][/size]
This is Cheat Menu [b]0.5.0[/b], tested on game version [b]0.11.6-alpha.1[/b] with Melvor Mod Loader 0.1.3. Open a character and press [b]F8[/b].

Your settings are [b]not written into your save file[/b]. They live in a small file next to the mod and are applied again each time you open that character. Remove the mod and the character is back to normal. Only what the Tools page gives you (items, currency, levels) stays.

[size=5][b]What is inside[/b][/size]
[b]Bank[/b]
[list]
[*]Extra bank slots (up to +10,000)
[*]Sell price multiplier
[*]Bone burying reward multiplier
[/list]
[b]XP and Speed[/b]
[list]
[*]XP multiplier for every skill
[*]Game speed: the whole game runs up to 20x faster
[*]Skill action speed, monster respawn speed. Skill action speed multiplies with a skill's own speed (x2 and x4 are x8)
[*]Higher offline progress limit
[/list]
[b]Skills[/b]
[list]
[*]Double product chance, keep materials chance, cheaper recipes
[*]Product quantity multiplier and extra products per action
[*]Woodcutting: instant cut chance. Thieving: never stunned.
[*]Astrology: knowledge per study, up to x1000
[/list]
[b]Combat[/b]
[list]
[*]God mode, damage, attack speed, accuracy, maximum hitpoints
[*]No death penalty, double loot chance
[*]Keep food, ammo, runes and prayer points
[*]Slayer coin multiplier, cheap slayer task rerolls
[/list]
[b]Per skill[/b]
[list]
[*]Its own XP multiplier for each of the 25 skills and its own speed for the 17 skills that perform actions
[*]"All skills at once": write one XP multiplier or one speed into every skill with a single click
[/list]
[b]Loot filter[/b]
[list]
[*]A searchable list of all 451 items that monsters and dungeons can drop, with icons
[*]Per item: keep it, sell it when it drops, or destroy it when it drops
[*]Only the dropped amount is affected. What is already in your bank is never touched.
[*]Show only the drops of the monster you are fighting right now
[/list]
[b]Materials[/b]
[list]
[*]Tired of mining Coal for every bar? Mark a material as "Not needed" and no recipe or item upgrade asks for it any more
[*]A searchable list of every material, the most used first, with the number of recipes that ask for it
[*]Your bank is never touched, and "Needed again" puts a material back
[/list]
[b]Tools[/b]
[list]
[*]Give any currency, give any item (with search)
[*]Auto-sell list: chosen items are sold from the bank as they arrive
[*]Set a skill level, set all levels, max all
[*]Skip time (as if the game had been closed), complete all quests
[/list]

[size=5][b]Made to be comfortable[/b][/size]
[list]
[*][b]No Apply button.[/b] A setting takes effect when you change it. Sliders apply when you let go, so dragging past a value does nothing on the way.
[*][b]See what is on.[/b] Active settings are highlighted and every section shows how many are switched on.
[*][b]Easy to undo.[/b] "Reset" on every row, "Reset all settings" with a second click to confirm.
[*][b]Respects your bank locks.[/b] A stack you have locked is never sold by the loot filter or by auto-sell.
[*][b]Works through the game's own bonus system,[/b] the same one that equipment, pets and prayers use. Nothing is patched.
[/list]

[size=5][b]Install[/b][/size]
[list=1]
[*]Install [b]Melvor Mod Loader[/b] first (see Requirements).
[*]Open the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files.
[*]Extract [b]CheatMenu-0.5.0.zip[/b] there. The mod ends up in [b]mods\CheatMenu[/b].
[*]Start the game from Steam as usual.
[/list]
No installer, no .exe, no script. Nothing is written outside the game folder.

[size=5][b]Uninstall[/b][/size]
Delete the folder [b]mods\CheatMenu[/b].

[size=5][b]Safe to download[/b][/size]
[list]
[*]One file: [b]CheatMenu.dll[/b]. No .exe, no .bat, no installer.
[*]The source code is public on GitHub (MIT license): what the file does can be read there.
[*]None of the game's own files are changed or included.
[/list]

[size=5][b]Good to know[/b][/size]
[list]
[*]Game speed makes the game run faster while you play. It does not change how fast the game computes offline progress.
[*]A speed setting also counts for crops that are already growing: the plots show their new time at once.
[*]On the Materials page, Farming recipes follow after the character has been opened again.
[*]Changing a slayer task is never completely free: the game charges at least 1 coin.
[*]With double loot at 100%, bones more than double, because they also get the game's separate bone bonus.
[*]Melvor Idle 2 is in alpha. After a game update a setting can stop working until the mod is updated; it is then skipped and named in the log.
[*]This mod changes the balance of the game. Use it the way you enjoy playing.
[/list]
