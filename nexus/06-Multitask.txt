Multitask

KATEGORI ONERISI (Category):
Miscellaneous

KISA ACIKLAMA (Summary / Brief overview):
Do more than one thing at a time in Melvor Idle 2. Switch a slot on and play as usual: when you start a new action, the one you were doing keeps running. Your last two or three actions run together, also offline. Nothing to set up. A cheat.

[size=5][b]Start here[/b][/size]
This is Multitask [b]0.2.0[/b], tested on game version [b]0.11.6-alpha.1[/b] with Melvor Mod Loader 0.1.3. Open a character, press [b]F5[/b] and switch a slot [b]ON[/b].

[b]This is a cheat.[/b] The game is balanced around one action at a time; this mod lets up to three run together. Use it if that is the game you want to play.

[size=5][b]How it works[/b][/size]
There is nothing to set up and nothing to pick.
[list]
[*][b]Slot 1 on:[/b] your last two actions run together.
[*][b]Slot 1 and 2 on:[/b] your last three actions run together.
[/list]
Fish, then start cooking: both run. Go mining, then start a fight: both run. Each at its normal speed, each with its normal rewards.

[size=5][b]You stay in charge, the way you already play[/b][/size]
[list]
[*][b]Start something new:[/b] it joins. With no room left, the oldest drops out.
[*][b]Press an action's own Stop button:[/b] that action is dropped. The others go on.
[*][b]Choose another rock, tree or recipe:[/b] that skill simply does the new thing. (A skill can only do one thing at a time.)
[*][b]Switch a slot off:[/b] what no longer fits is stopped. With both off, the mod does nothing at all.
[/list]

[size=5][b]It looks after itself[/b][/size]
[list]
[*][b]It waits for materials.[/b] Cooking or smithing pauses when it runs out and goes on when there is more. It works in small piles (about ten at a time) so the game does not report "action stopped" for every single fish.
[*][b]It does not walk back into a fight.[/b] A fight is dropped if your character dies.
[*][b]It works while you are away.[/b] Everything that was running when you closed the game goes on in the game's own offline progress.
[*][b]It never bypasses requirements.[/b]
[/list]

[size=5][b]Works with Action Queue[/b][/size]
With [url=https://www.nexusmods.com/melvoridle2/mods/5]Action Queue[/url] 0.4.1 or newer, the queue's steps come and go as your latest action while what you were doing before keeps running beside them. A finished step is not kept going, and if the queue needs a skill you were using, the queue gets it.

[size=5][b]Good to know[/b][/size]
[list]
[*]An action that runs out of materials while the game is closed stays stopped until you are back.
[*]Hunting needs a trap and Agility needs a path chosen on the skill's own page first.
[*]The game's bottom bar shows your latest action. The others are listed in the F5 window.
[*]All 16 skills the Action Queue knows are supported, including dungeons.
[/list]

[size=5][b]Install[/b][/size]
[list=1]
[*]Install [b]Melvor Mod Loader[/b] first (see Requirements).
[*]Open the game folder: Steam > right-click Melvor Idle 2 > Manage > Browse local files.
[*]Extract [b]Multitask-0.2.0.zip[/b] there. The mod ends up in [b]mods\Multitask[/b].
[*]Start the game from Steam as usual.
[/list]
No installer, no .exe, no script. Nothing is written outside the game folder.

[size=5][b]Uninstall[/b][/size]
Switch the slots OFF and delete the folder [b]mods\Multitask[/b]. Your save needs no clean-up: without the mod, extra actions simply stop the next time you start anything.

[size=5][b]Safe to download[/b][/size]
[list]
[*]One file: [b]Multitask.dll[/b]. No .exe, no .bat, no installer.
[*]Open source: read or build the code yourself on [url=https://github.com/falorfrozen-cmd/MelvorModLoader]GitHub[/url].
[*]None of the game's own files are changed or included.
[/list]
